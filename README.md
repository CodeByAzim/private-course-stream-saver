# Private Course & Stream Saver

[![Download Extension](https://img.shields.io/badge/Download_Extension-v1.0.0_(ZIP)-2ea44f?style=for-the-badge&logo=googlechrome&logoColor=white)](https://github.com/CodeByAzim/private-course-stream-saver/releases/download/v1.0.0/universal-media-saver.zip)

> **Click the green button above to download the `.zip` file directly.**

A lightweight Chrome extension built by **CodeByAzim** to detect and download online course videos and web streams with automatic caption support for offline study.

## ✨ Key Features
* **Multi-Stream Detection:** Supports HLS (`.m3u8`), DASH (`.mpd`), signed `.mp4`, and `blob:` video streams.
* **Subtitle & Caption Fallback:** Automatically detects and saves available video captions/subtitles.
* **Quick Frame Capture:** Built-in option to capture clean screenshots from active video players.
* **Lightweight & Fast:** Runs locally in your browser with zero external server tracking.

## 🛠️ How to Install (Chrome / Brave / Edge)
1. Click the **Download Extension** button at the top to get the `.zip` file.
2. **Extract (unzip)** the downloaded file to a permanent folder on your PC.
3. Open your browser and go to `chrome://extensions` (or `edge://extensions` / `brave://extensions`).
4. Turn ON **Developer mode** in the top-right corner.
5. Click **Load unpacked** in the top-left corner and select the extracted extension folder.
6. Pin the extension to your toolbar and reload your course video page to start capturing streams.
